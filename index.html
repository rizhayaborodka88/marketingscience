Частотность запросов Wordstat

Вставьте список запросов — получите количество показов за 30 дней через Yandex Wordstat API.

Как это работает

Токен и запросы остаются в браузере и уходят только на указанный прокси/API. Браузер не может обращаться к api.wordstat.yandex.net напрямую, если API не отдаёт CORS-заголовки, поэтому в репозитории есть готовый воркер worker/worker.js (см. README). Если CORS у API разрешён — оставьте поле прокси пустым.
