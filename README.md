# Wordstat — проверка частотности запросов

Статический сайт (один `index.html`) для массовой проверки частотности через Yandex Wordstat API (`POST /v1/topRequests`, поле `totalCount`).

## Запуск
1. Получите OAuth-токен и доступ к Wordstat API (документация Яндекса).
2. Settings → Pages → Source: **GitHub Actions**. Сайт задеплоится при пуше в `main`.
3. Откройте сайт, введите токен, вставьте запросы, нажмите «Проверить». Результат можно отсортировать, скопировать или скачать в CSV.

## CORS-прокси
Браузер может быть заблокирован CORS при прямом обращении к API. Тогда задеплойте `worker/worker.js` как Cloudflare Worker (бесплатно), в `ALLOWED_ORIGIN` пропишите адрес своего Pages-сайта и вставьте URL воркера в поле «Прокси». Токен воркер не хранит.

Лимиты API (≈10 запросов/сек, суточная квота) — сайт шлёт ~6 запросов/сек и повторяет запрос при 429.
